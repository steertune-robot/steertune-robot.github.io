# Steertuning

Anonymous research project page for **Steertuning Policies from a Few Human Videos**, Paper ID 1039.

GitHub Pages publishes `main` from the repository root at https://steertune-robot.github.io/.

The page contains the project teaser, interactive method and architecture figures, manuscript results, six human/robot task pairs, and three full-stack rollouts. Author names, affiliations, personal links, source manifests, and private file paths are omitted. The supplied paper already uses Paper ID 1039 and has blank author metadata. Search indexing is discouraged.

All 24 non-teaser video assets have no audio streams. The teaser retains its supplied audio and starts muted. Media loads near the viewport, pauses offscreen, and respects reduced-motion preferences. Numerical charts preserve manuscript values and label digitized curves as approximate. Diagram motion is schematic and separate from recorded videos.

Third-party runtime and font licenses are retained in `vendor/` and `assets/fonts/`. The small Gemini PNG identifies the VLM and comes from Google's official Gemini site.
